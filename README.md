## 📥 Instalación Local

<details>
  <summary><b>👇 Clic para ver instrucciones de instalación</b></summary>

  Si querés clonar esto:

  ```bash
  # 1. Cloná el repo
  git clone https://github.com/HugoAleOlguin/jueguitos-piola.git

  # 2. Entrá a la carpeta
  cd jueguitos-piola

  # 3. Abrí el index.html en tu navegador.
  ```
