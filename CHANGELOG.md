# Changelog

Historial de cambios estructurales y visuales del proyecto.

---

## Marzo 2026

**30 de Marzo**
- **[3.8.0] - Minimalismo e Hiper-Compacto**:
  - **Ajustes de Interfaz**: Reducción de rellenos, fuentes y márgenes para una navegación rápida.
  - **Responsive Pro Max**: Rediseño vertical de la página de detalle e implementación de 3 columnas para tablets.
  - **Bypass de FX**: Desactivación de partículas, rastro de ratón y animaciones pesadas para maximizar rendimiento.
  - **Configuración Simplificada**: Modal de ajustes reducido a Fondo, Diseño y Temas.

**28 de Marzo**
- **[4.0.0] - Admin Panel v3 (SPA)**:
  - Nueva arquitectura SPA para el panel de administración.
  - Integración nativa con la API de GitHub para guardado directo.
  - Diseño utilitario optimizado para productividad.

**27 de Marzo**
- **[3.7.0] - Modal por Pestañas**:
  - Navegación por categorías y Sidebar en escritorio.
  - Responsive mejorado con chips horizontales.

**25 de Marzo**
- **[3.6.0] - Sistema de Tarjetas**:
  - Estilos Estándar y Compacto.
  - Persistencia en la nube.

---

## Febrero 2026

**17-20 de Febrero**
- Simplificación masiva de código (eliminación de bypass y easter eggs pesados).
- Refactor de `theme.js` y eliminación de páginas muertas.
- Acceso Admin restaurado.

**2-3 de Febrero**
- Sistema de Logros (beta) y Modo Versus (Torneo).
- Notificaciones inyectadas para visibilidad garantizada.
